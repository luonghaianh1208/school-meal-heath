# Project Overview

## Mục tiêu (Objective)
Dự án School Meal Health là một hệ thống quản lý sức khỏe và bữa ăn học đường, cung cấp các tính năng theo dõi bữa ăn, tính toán dinh dưỡng, và tích hợp AI để đưa ra thông tin chi tiết về sức khỏe của học sinh.

## Phạm vi (Scope)
- Quản lý học sinh (Students)
- Theo dõi bữa ăn (Meal Tracking)
- Tính toán dinh dưỡng (Nutrition Calculation)
- Phân tích và Insight từ AI (AI Insights)
- Báo cáo thống kê (Reports)
- Xác thực người dùng (Authentication)
- Bảng điều khiển tổng quan (Dashboard)

## Tech Stack
- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS, Framer Motion
- **Icons & Charts:** Lucide React, Recharts
- **Backend/BaaS:** Firebase (Authentication, Firestore)
- **AI Integration:** Google Gemini API (`@google/genai`)
- **Routing:** React Router v7
